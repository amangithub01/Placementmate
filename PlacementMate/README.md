# PlacementMate

A simple placement deadline tracker for students.

## Run the project
1. Extract `PlacementMate.zip`.
2. Open the `index.html` file in Chrome, Edge, or another modern browser.
3. Add a company, role, category, closing date, closing time, and optional application link.

## Features
- Add, edit, and delete placement opportunities.
- View company, pending, and completed counts.
- Live countdown displayed on the right side of each opportunity card.
- Red highlight for deadlines within 48 hours.
- Search by company or role.
- Filter by status and category.
- Mark an application as completed or undo it.

## Important note
This is a front-end prototype. Entries are stored in memory only and are cleared when the page is refreshed or closed. No backend or database is included.
